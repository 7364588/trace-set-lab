# Security

Report vulnerabilities through this repository's private vulnerability reporting feature.
Use synthetic examples and remove credentials, private source code and production traces.
If private reporting is unavailable, request a private channel without posting sensitive details.

Only the latest released version receives fixes. See the README for input limits and scope.
Generated reports contain data from their input files; inspect them before sharing.
The synthetic demo contains no production data. Reports load no third-party scripts or fonts.
